# RV64-M8 性能与验收

## 两种执行模式

- `Fast`：使用 RV64 独立 Sv39 TLB 和 1024 项直接映射译码缓存。
- `Reference`：每次执行直接译码；启用 Sv39 时每次重新遍历页表。

两种模式共享同一套指令执行、CSR、权限、异常和提交逻辑。快速模式没有
跳过地址对齐、页权限、A/D 位、Trap、CSR 或总线错误检查。译码缓存以完整
原始指令和指令长度为键，指令字节仍会在每一步重新取回，因此不会把旧指令
字节当作新指令执行；`FENCE.I` 会清空译码缓存。

## 性能计数

RV64 Core 独立记录：

- step、退休指令、同步 Trap、中断 Trap 和 WFI 空闲返回；
- 取指次数、半字读取、16 位与 32 位指令数；
- TLB 命中/未命中、页表遍历、PTE 读写和翻译故障；
- 译码缓存命中、未命中和失效。

整机退出时还输出吞吐率、按访问类型分类的总线读写、设备查找缓存和
Framebuffer 写入带宽。它们是诊断统计，不改变客户机可见状态。

## 自动验收

```powershell
cmake --preset debug
cmake --build --preset debug
ctest --preset debug --output-on-failure

cmake --preset release
cmake --build --preset release
ctest --preset release --output-on-failure
```

只运行 M8 相关测试：

```powershell
ctest --test-dir build/debug `
  -R "rv64_(core|mmu|mode_differential|performance)" `
  --output-on-failure
```

运行可重复的参考/快速性能基准：

```powershell
.\build\release\rv64_performance_runner.exe 1000000
```

当前宿主的 Release 百万步基线为：

```text
reference: 17.59 Msteps/s
fast:      21.86 Msteps/s
speedup:   1.24x
```

真实 OpenSBI S-mode 验收约为 11.50 Msteps/s，译码缓存命中率约
72.85%。这些数字受宿主负载和编译器影响，不作为跨机器的固定阈值；
自动测试要求退休数、最终状态和参考/快速结果一致。

`rv64_mode_differential_tests` 会让两台独立 Machine 逐步运行相同的整数、
访存、循环和分支程序，并逐项比较 StepResult 与完整 CpuSnapshot。
`rv64_architecture_runner` 还支持以下外部镜像轨迹：

```powershell
.\build\debug\rv64_architecture_runner.exe --trace `
  .\build\debug\architecture64\rv64uc-rvc.bin

.\build\debug\rv64_architecture_runner.exe --trace --reference `
  .\build\debug\architecture64\rv64uc-rvc.bin
```

两份轨迹必须完全一致；之后仍可通过
`tests/differential/compare_spike.py --xlen 64` 与 Spike 比较。

## Linux 验收

按照 [`docs/BOOT.md`](BOOT.md) 启动 RV32 和 RV64。RV64 至少确认：

```sh
uname -a
cat /proc/cpuinfo
free -h
df -h
dmesg | grep -E 'Memory:|virtio_blk|vda|EXT4|ttyS0|simple-framebuffer'
poweroff
```

通过标准：

- OpenSBI 进入 S-mode，Linux 进入 Buildroot Shell；
- CPU 显示 RV64IMAC、MMU 显示 Sv39；
- VirtIO `/dev/vda` 以 ext4 可读写挂载；
- UART、Framebuffer、键盘和 SBI 关机正常；
- 退出时出现 `RV64-M8 performance statistics`；
- Debug、Release 和 RV32 全量回归无退化。

外部软件的完整配置快照和重建命令见 `configs/README.md`。
