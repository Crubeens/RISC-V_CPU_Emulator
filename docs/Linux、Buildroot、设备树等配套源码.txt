Linux、OpenSBI、Buildroot 与设备树配套说明
==========================================

本项目不把大型上游源码树放入 Git。外部软件在 WSL/Ubuntu 中独立编译，
最终二进制复制到项目根目录 boot-images/；项目自己的 DTS 位于
platform32/dts/ 和 platform64/dts/，构建时生成对应 DTB。
实际启动成功的完整 Linux/Buildroot 配置快照和重建命令保存在
configs/README.md、configs/linux/ 和 configs/buildroot/。

一、固定版本

- OpenSBI：v1.8.1
  上游：https://github.com/riscv-software-src/opensbi
- Linux：v6.12.96
  上游：https://git.kernel.org/pub/scm/linux/kernel/git/stable/linux.git
- Buildroot：2025.02.16
  上游：https://buildroot.org/download.html
- Spike：固定提交记录见 tests/differential/SPIKE_REVISION.md
  上游：https://github.com/riscv-software-src/riscv-isa-sim

二、当前 RV32 镜像

- boot-images/opensbi-v1.8.1-rv32-fw_jump.bin
- boot-images/linux-v6.12.96-rv32ima-Image
- boot-images/buildroot-2025.02.16-rv32ima-rootfs.ext4
- build/<配置>/images/rv32-virt.dtb

Linux/用户态目标：RV32IMA、ILP32、单 Hart、Sv32、无 F/D/V。

三、当前 RV64 镜像

- boot-images/opensbi-v1.8.1-rv64-fw_jump.bin
- boot-images/linux-v6.12.96-rv64imac-Image
- boot-images/linux-v6.12.96-rv64gc-Image
- boot-images/rootfs-buildroot-v2025.02.16-rv64imac.ext4
- boot-images/debian-13-riscv64-apt.ext4
- build/<配置>/images/rv64-virt.dtb

Buildroot 快速基线使用 RV64IMAC、LP64、单 Hart、Sv39、musl、BusyBox
和 128 MiB ext4。Debian 使用 RV64GC、LP64D 和 768 MiB ext4；对应内核
必须使用启用 `CONFIG_FPU` 的 RV64GC 配置。

四、职责边界

- OpenSBI 提供 M-mode 固件和 SBI 服务。
- Linux 内核运行在 S-mode。
- Buildroot 生成根文件系统和用户态程序，不是引导程序。
- DTS/DTB 描述 RAM、CPU、UART、CLINT、PLIC、VirtIO、Framebuffer 和
  Syscon 地址布局；必须与对应 platform32/ 或 platform64/ 常量一致。
- boot-images/ 被 Git 忽略并作为持久外部产物保存；build/ 是可随时重建
  的 CMake 输出目录。

五、Debian 13 riscv64 APT 镜像

- 生成脚本：scripts/build_debian_rv64_rootfs.sh
- 输出镜像：boot-images/debian-13-riscv64-apt.ext4（768 MiB）
- 软件源：Debian 13 trixie 官方 riscv64 仓库
- 网络：RV64 VirtIO Net + libslirp DHCP/DNS/NAT
- 时间：Goldfish RTC，使用宿主实时时间

Debian 官方 riscv64 使用 RV64GC/LP64D。RV64-M10 已完成完整 F/D 标量
实现、官方架构测试、Spike 差分和 RV64GC ISA 宣告；已验证动态加载器、
systemd PID 1、shell、apt 可执行文件与 DHCP。RV64-M11.3 已通过 Debian
官方 HTTPS 源完成 apt update、包安装/运行/升级、关机持久化、再次启动、
卸载和损坏包拒绝验收。M11.4 又覆盖断网、错误源、TLS 公钥错误与空间不足，
并在失败后复查 dpkg 数据库。详细记录见 core64/RV64_M9_M11_PLAN.md。
