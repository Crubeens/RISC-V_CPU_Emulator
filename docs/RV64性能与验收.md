# RV64 性能与验收

## 执行模式

- `Fast`：使用 RV64 独立的 Sv39 TLB、1024 项原始指令译码缓存，以及
  4096 项直接映射指令前端缓存。
- `Reference`：不使用上述缓存；每次执行直接译码，启用 Sv39 时每次重新遍历页表。

两种模式共享同一套指令执行、CSR、特权级、异常、提交和总线语义。快速模式不会
跳过地址对齐、页权限、A/D 位、Trap、CSR 或总线错误检查。

指令前端缓存以虚拟 PC、完整 `satp` 和当前特权级为上下文，只缓存总线明确标记为
可缓存的内存。命中后可省去重复的地址翻译、取指总线读取和译码。MMIO 不进入缓存；
跨 4 KiB 页边界的 32 位指令沿用完整慢路径。`FENCE.I`、`SFENCE.VMA`、执行模式
切换和复位具有确定的失效语义，自修改代码必须按 RISC-V 规范执行 `FENCE.I`。

## 性能计数

RV64 Core 独立记录：

- step、退役指令、同步 Trap、中断 Trap 和 WFI 空闲返回；
- 取指次数、半字读取、16 位与 32 位指令数；
- TLB 命中/未命中、页表遍历、PTE 读写和翻译故障；
- 译码缓存和指令前端缓存的命中、未命中与失效。

整机退出时还输出吞吐率、按访问类型分类的总线读写、设备查找缓存、设备轮询和
Framebuffer 写入带宽。这些只用于诊断，不改变客户机可见状态。

## 自动验收

```powershell
cmake --preset debug
cmake --build --preset debug
ctest --preset debug --output-on-failure

cmake --preset release
cmake --build --preset release
ctest --preset release --output-on-failure
```

只运行性能相关测试：

```powershell
ctest --test-dir build/debug `
  -R "rv64_(core|mmu|mode_differential|performance)" `
  --output-on-failure
```

运行可重复的参考/快速微基准：

```powershell
.\build\release\rv64_performance_runner.exe 10000000
```

2026-08-01 当前宿主 Release 千万步结果约为：

```text
reference: 19.48 Msteps/s
fast:      28.56 Msteps/s
speedup:   1.47x
```

加入指令前端缓存前，相同宿主快速模式约为 18.32 Msteps/s；当前约提升 55.9%。
数值受宿主负载和编译器影响，只作为本机回归基线，不作为跨机器固定阈值。

真实 OpenSBI + Linux 的 2 亿 machine-step 运行约为 11.99 Msteps/s；约 2 亿次取指中，
指令前端缓存命中率为 84.01%，实际取指半字总线读取降至约 4560 万次。真实系统的
磁盘、网络、Framebuffer 和空闲等待比例会改变最终吞吐率。

`rv64_mode_differential_tests` 让两台独立 Machine 逐步运行相同程序，并逐项比较
`StepResult` 与完整 `CpuSnapshot`。`rv64_architecture_runner` 还支持生成两种模式的
外部轨迹：

```powershell
.\build\debug\rv64_architecture_runner.exe --trace `
  .\build\debug\architecture64\rv64uc-rvc.bin

.\build\debug\rv64_architecture_runner.exe --trace --reference `
  .\build\debug\architecture64\rv64uc-rvc.bin
```

两份轨迹必须一致；之后仍可通过
`tests/differential/compare_spike.py --xlen 64` 与 Spike 比较。

## Linux 验收

按照 [启动说明](BOOT.md) 启动 RV64，至少确认：

```sh
uname -a
cat /proc/cpuinfo
free -h
df -h
dmesg | grep -E 'Memory:|virtio_blk|vda|EXT4|ttyS0|simple-framebuffer'
poweroff
```

通过标准：

- OpenSBI 进入 S-mode，Linux 进入 Buildroot 或 Debian；
- CPU、Sv39、VirtIO ext4、UART、Framebuffer、键盘和 SBI 关机正常；
- 退出时出现 `RV64 performance statistics`，且指令前端缓存存在有效命中；
- Reference/Fast 差分、Debug、Release 和 RV32 全量回归无退化。

外部软件的完整配置快照和重建命令见 [`configs/README.md`](../configs/README.md)。
