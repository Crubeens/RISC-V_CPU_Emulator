RISC-V CPU Emulator 启动命令
================================

以下命令均在项目根目录的 PowerShell 中执行。
省略 --cpu 时默认使用 RV32。

一、RV32 Linux + 可回写 ext4 虚拟磁盘

.\build\release\riscv_emulator.exe --cpu rv32 --boot-disk `
  ".\boot-images\opensbi-v1.8.1-rv32-fw_jump.bin" `
  ".\boot-images\linux-v6.12.96-rv32ima-Image" `
  ".\build\release\images\rv32-virt.dtb" `
  ".\boot-images\buildroot-2025.02.16-rv32ima-rootfs.ext4"

二、RV64 Linux + 可回写 ext4 虚拟磁盘

.\build\release\riscv_emulator.exe --cpu rv64 --ram-mib 512 --boot-disk `
  ".\boot-images\opensbi-v1.8.1-rv64-fw_jump.bin" `
  ".\boot-images\linux-v6.12.96-rv64imac-Image" `
  ".\build\release\images\rv64-virt.dtb" `
  ".\boot-images\rootfs-buildroot-v2025.02.16-rv64imac.ext4"

RV64 网络默认启用，不需要管理员权限或 TAP 网卡。
Buildroot 已验证 DHCP 地址 10.0.2.15、网关 10.0.2.2、DNS 10.0.2.3。
RV64 虚拟磁盘使用文件后端，启动时不会把整个 ext4 镜像复制到宿主内存；
正常退出会刷新已发生的磁盘写入。
--ram-mib 必须放在具体命令之前；支持 64 到 4096 MiB，省略时为 256 MiB。
模拟器会把实际容量同步写入传入的 RV64 DTB。Debian 建议至少使用 512 MiB；
该 RAM 当前等量占用宿主内存，因此不应超过宿主机可用内存。

Debian 13 APT 镜像名：
  boot-images/debian-13-riscv64-apt.ext4

Debian 13 RV64GC/LP64D：

.\build\release\riscv_emulator.exe --cpu rv64 --ram-mib 512 --boot-disk `
  ".\boot-images\opensbi-v1.8.1-rv64-fw_jump.bin" `
  ".\boot-images\linux-v6.12.96-rv64gc-Image" `
  ".\build\release\images\rv64-virt.dtb" `
  ".\boot-images\debian-13-riscv64-apt.ext4"

M11.3 已验证公网 DNS/HTTPS、apt update、hello 包的安装/运行/升级、关机后
持久化、再次启动和卸载，并验证损坏的 deb 包会被拒绝。解释执行下首次更新
软件索引和维护包数据库会明显慢于真实硬件，开机输出短暂停顿不等于死机。
M11.4 进一步验证断网代理、无效 Debian suite、错误 TLS 公钥指纹和 16 KiB
空间不足均确定失败，之后 dpkg --audit 仍为空。

三、SDL 图形界面

在 --boot 或 --boot-disk 前增加 --gui，例如：

.\build\release\riscv_emulator.exe --cpu rv64 --ram-mib 512 --gui --boot-disk `
  ".\boot-images\opensbi-v1.8.1-rv64-fw_jump.bin" `
  ".\boot-images\linux-v6.12.96-rv64imac-Image" `
  ".\build\release\images\rv64-virt.dtb" `
  ".\boot-images\rootfs-buildroot-v2025.02.16-rv64imac.ext4"

F1：UART 终端
F2：客户机 Framebuffer

四、可选步数上限

在命令最后追加正整数可限制 machine steps，例如 100000000。
不追加时，--boot-disk 会持续运行到客户机请求关机。

五、镜像位置

boot-images 目录位于项目根目录，不在 build 目录内。
删除或重新生成 build 目录不会覆盖 OpenSBI、Linux 和根文件系统镜像。
